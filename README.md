# IIS Multi TL LAN Chat (chat.aspx)

Windows の IIS (Internet Information Services) + ASP.NET 環境で動作する、**完全ビルド不要の単一ファイル型ローカルLANチャットアプリ** です。

`chat.aspx` ファイルを1本 `C:\inetpub\wwwroot\` に配置するだけで、同一Wi-Fi/LAN内のスマホ（iPhone/iPad/Android）やPCからすぐに利用できます。

---

## 🔥 特長

- **完全ビルド不要**: `.aspx` ファイルをIISの公開ディレクトリに置くだけで即座に動作します。
- **マルチタイムライン（スレッド）対応**: ＋ボタンから自由なテーマでスレッドを作成・切替できます。
- **画像送信 ＆ 自動軽量化**: スマホで撮影した高画質写真をクライアント側（JavaScript/Canvas）で自動圧縮して送信します。
- **自動ソート機能**: 新規投稿（テキスト・画像）があったスレッドは自動的に一番上へ移動します。
- **電子着信音通知**: Web Audio API を使用し、新着メッセージ受信時に「ピロン♪」と通知音を鳴らします。
- **データ非永続（プライバシー配慮）**: メッセージや画像はサーバーのメモリ（C# `static` 変数）上に保持されます。PCの電源を切るかIISをリセットするとデータはすべて自動消去されます。

---

## 🛠 前提条件

- **OS**: Windows 10 / 11 / Windows Server
- **Webサーバー**: IIS (Internet Information Services)
- **アプリケーション機能**: ASP.NET 4.x (4.6 / 4.7 / 4.8 など)

---

## 🚀 セットアップ手順

### 1. Windows 機能の有効化（初回のみ）
1. `Win + R` キーを押し、`optionalfeatures` と入力してEnterを押します。
2. **「インターネット インフォメーション サービス」** にチェックを入れます。
3. **「ワールド ワイド ウェブ サービス」** ＞ **「アプリケーション開発機能」** 内の **「ASP.NET 4.8」**（または 4.x 系）にチェックを入れて「OK」をクリックします。

### 2. ファイアウォールとネットワークの設定
1. **ファイアウォール許可**: コントロールパネルの「Windows Defender ファイアウォールを介したアプリの許可」で、**「ワールド ワイド ウェブ サービス (HTTP)」** のプライベート接続を許可します。
2. **ネットワークプロファイル**: Windowsの設定から、接続中のWi-Fi/イーサネットのプロファイルを **「プライベート ネットワーク」** に設定します。
